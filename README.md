# TMT Marmoraria, Vidraçaria e Móveis Planejados

Cópia independente personalizada do template enviado. HTML, CSS e JavaScript sem dependências de execução; componentes, seções, responsividade e interações preservados.

## Executar
Node.js 18 ou superior. Execute `npm run dev` e abra o endereço mostrado no terminal.

## Validar e gerar
`npm run validate`
`npm run build`
`npm run preview`

## GitHub e Vercel
Extraia este ZIP e envie o conteúdo desta pasta para um novo repositório GitHub. Importe o repositório na Vercel. Framework: Other; Build Command: npm run build; Output Directory: dist. O arquivo vercel.json já contém a configuração. Não precisa de variáveis de ambiente.

## Conteúdo
- public/index.html: informações e seções.
- src/components/content.js: serviços, galeria, dúvidas e número de WhatsApp.
- src/styles.css: estilos originais e paleta TMT.
- public/assets: imagens e fontes locais.
